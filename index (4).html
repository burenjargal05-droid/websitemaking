Төлөвлөх

Код бичихээсээ өмнө юу хийхээ тодорхойл. Төлөвлөгөөгүй эхэлбэл дундаа олон удаа дахин эхэлнэ.

  • Зорилго: Сайт юуны төлөө вэ? (танилцуулга, портфолио, бизнес, блог)
  • Үзэгчид: Хэн үзэх вэ? Ямар мэдээлэл хайх вэ?
  • Хуудсууд: Нүүр, Бидний тухай, Үйлчилгээ, Холбоо барих гэх мэт.
  • Агуулга: Текст, зураг, лого, холбоо барих мэдээллээ урьдчилан бэлд.
  • Загвар: 2–3 өнгө, 1–2 фонт сонго. Цаасан дээр хуудасны схем (wireframe) зур.
ЗөвлөгөөАнхны сайтаа нэг хуудастай (one-page) байлгаж, жижиг эхэл. Дараа нь томруулна.

Хэрэгсэл бэлдэх

Вэбсайт хийхэд үнэтэй программ хэрэггүй. Дараах хоёр зүйл хангалттай:

  • Кодын редактор: Visual Studio Code (үнэгүй). Эсвэл Notepad++, Sublime Text.
  • Хөтөч: Chrome, Firefox, Edge. Үр дүнг үзэх, алдааг хайхад хэрэглэнэ.

Компьютер дээрээ my-site нэртэй хавтас үүсгэ. Дотор нь дараах бүтэцтэй байлга:

НэршилФайл, хавтасны нэрийг жижиг латин үсгээр, зайгүй (my-photo.jpg) бичих нь зүйтэй. Нүүр хуудас заавал index.html байна.

HTML – хуудасны бүтэц

HTML нь агуулгыг таг (tag)-аар тэмдэглэж, ямар хэсэг нь гарчиг, нь догол мөр, нь зураг болохыг хөтчид хэлж өгдөг. index.html файлаа үүсгээд дараах суурь кодыг бич:

CSS – загвар оруулах

CSS нь HTML-ийн элементүүдийн өнгө, хэмжээ, байрлалыг тодорхойлно. Бичих хэлбэр нь: сонгогч { шинж чанар: утга; }

Үндсэн ойлголтууд

  • Box model: Элемент бүр content, padding, border, margin гэсэн давхарга бүхий хайрцаг. box-sizing:border-box нь хэмжээг тооцоход хялбар болгоно.
  • Flexbox: Нэг чиглэлд (мөр эсвэл багана) элементүүдийг эгнүүлэх, зайг нь тохируулах.
  • Grid: Хоёр чиглэлд (мөр ба багана) торлон байрлуулах.
  • CSS хувьсагч: --main шиг нэг утгыг нэг удаа тодорхойлж олон газарт ашиглах.

Утсанд зохицуулах (Responsive)

Ихэнх хүн сайтыг утаснаасаа үздэг. Тиймээс хуудас дэлгэцийн хэмжээнд зохицох ёстой. Гурван зүйл анхаар:

  1. <meta name="viewport"…> таг заавал head-д байх.
  2. Хэмжээг тогтмол пикселээр биш %, rem, max-width-аар өг.
  3. Дэлгэцийн хэмжээнээс хамаарч загвар солих media query ашигла.
Шалгах аргаХөтөч дээр F12 дараад «device toolbar» (утасны дүрс)-аар утасны дэлгэц дээр ямар харагдахыг үзнэ.

JavaScript – амьдруулах

JavaScript нь хуудсанд үйлдэл нэмнэ: товч дарахад цэс нээх, маягт шалгах, өгөгдөл өөрчлөх гэх мэт. Жишээ нь тоолуур:

Үндсэн алхам нь: 1) элементийг олох (getElementById, querySelector), 2) үйлдэл сонсох (addEventListener), 3) хуудсыг өөрчлөх (textContent, classList).

Зураг, дүрс, фонт нэмэх

  • Формат: зурагт WebP/JPG, лого, дүрсэнд SVG, тунгалаг арын зурагт PNG.
  • Хэмжээ: зургийг сайтад хэрэгтэй хэмжээнд нь багасга. Хэдэн МБ-ын зураг сайтыг удаашруулна.
  • alt текст: зураг бүрт товч тайлбар бич. Хараагүй хэрэглэгч, хайлтын системд хэрэгтэй.
  • Эрх: зургийг өөрөө авсан эсвэл үнэгүй лицензтэй (Unsplash, Pexels) эх сурвалжаас ав.
  • Фонт: Google Fonts-оос Кирилл үсэг дэмждэг фонтыг сонго.

Шалгах, засах

  • Хөтөч бүр дээр: Chrome, Firefox, Edge, утасны хөтөч дээр нээж үз.
  • Алдаа хайх: F12 → Console дээр улаан алдаа байгаа эсэхийг хар.
  • Элемент шалгах: F12 → Elements дээр хулганаар элемент сонгож CSS-ийг шууд өөрчилж туршиж болно.
  • Холбоос, зураг: бүх холбоос ажиллаж, зураг ачаалж байгаа эсэхийг шалга.
  • Хурд, чанар: Chrome-ийн Lighthouse хэрэгслээр хурд, хүртээмж, SEO-г дүгнүүл.
  • Үсгийн алдаа: бүх текстээ дахин уншиж шалга.
Дараагийн алхамСайт бэлэн болсон бол интернетэд нийтлэх (GitHub Pages, сервер) шаардлагатай. Үүнийг тусдаа гарын авлагад тайлбарласан.

Шууд туршиж үзэх талбар

Код өөрчлөөд баруун талд үр дүнг нь шууд хар. Бэлэн жишээг сонгоод засаж үзээрэй.

Түгээмэл асуулт

Программчлал мэдэхгүй байхад хийж болох уу?

Болно. HTML ба CSS нь программчлал биш, тэмдэглэгээ ба загварын хэл тул хэдхэн өдрийн дотор анхны хуудсаа хийж чадна. JavaScript-ийг дараа нь аажмаар сурна.

Бэлэн загвар (template) ашиглаж болох уу?

Болно. Бэлэн загвараас эхэлж, агуулга, өнгийг нь өөрчлөх нь хурдан арга. Лицензийг заавал шалга. Мөн кодыг нь ойлгон өөрчилж сурах нь чухал.

Код бичихгүйгээр сайт хийх арга бий юу?

Wix, WordPress, Webflow зэрэг платформууд код бичихгүйгээр сайт хийх боломж олгодог. Гэхдээ хязгаартай, зарим нь төлбөртэй. Код сурбал бүрэн хяналт авна.

Дараа нь юу сурах вэ?

Git ба GitHub, CSS framework (Tailwind), JavaScript-ийн гүнзгий мэдлэг, дараа нь React зэрэг framework, backend (Node.js) гэх мэт дарааллаар сурч болно.

Сайт хийж дууссаны дараа яах вэ?

Файлуудаа хостинг дээр байрлуулж нийтэлнэ. Хамгийн хялбар нь GitHub Pages юм.
